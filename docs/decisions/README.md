# Decision Records

Use a short, dated record for decisions that affect the robot's requirements, architecture, components, fabrication, control approach, or schedule. Create records from `template.md` and name them `YYYY-MM-DD-short-title.md`.

Keep the record even if the decision is later reversed. Add a follow-up record or update its status with a link to the new decision; do not erase the original reasoning. Link related experiments and journal entries so the evidence behind a choice is easy to trace.
