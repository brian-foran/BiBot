# Mechanical: Frame

Store robot-frame requirements, CAD source and exports, print preparation, fabrication records, and fit or strength checks here. Keep editable source files alongside exported formats where practical, and identify units, revision, material, printer, and slicer settings for fabricated parts.

For each meaningful design or print iteration, link a dated journal entry and record the reason for the change. Capture dimensions, mass, tolerances, print failures, and assembly observations where they affect later choices.
